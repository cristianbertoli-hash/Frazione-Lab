FRA1E protetto con password

Cifra l'intero FRA1 con AES-GCM. La password viene trasformata in chiave con PBKDF2-HMAC-SHA256 (600.000 iterazioni). Tutto avviene localmente nel browser: foto e password non vengono inviate a GitHub.

AES-128 e AES-256 producono file della stessa dimensione. FRA1E aggiunge 64 byte al FRA1: la cifratura protegge i dati ma non li comprime.

FRA1 / FRA1E → recupera foto originale

L'app riconosce automaticamente un FRA1 normale oppure un FRA1E AES-128/AES-256 leggendo l'intestazione interna. Il nome del file non serve per riconoscere la cifratura.

Cosa significa “frazione” qui?

Il file FRA1 è interpretato come un unico intero binario N. Se il pacchetto contiene K bit, la rappresentazione matematica è N / 2^K. Per foto grandi non mostriamo N in decimale: avrebbe milioni di cifre. FRA1E cifra quel pacchetto FRA1 senza perdita.
