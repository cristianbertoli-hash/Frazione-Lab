Cosa significa “frazione” qui?

Il file FRA1 è interpretato come un unico intero binario N. Se il pacchetto contiene K bit, la rappresentazione matematica è N / 2^K. Per foto grandi non mostriamo N in decimale: avrebbe milioni di cifre. Il file .fra1 conserva N completo in forma binaria, senza perdita.
